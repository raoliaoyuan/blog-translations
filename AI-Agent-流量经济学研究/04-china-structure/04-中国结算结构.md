# 第四部分　中国互联网结算的特殊结构

> 内部研究报告 · 草稿 v0.1 · 证据强度：**已发布数据（监管/年报）+ 行业共识**

中国语境的特殊性在于：互联网互联结算不是单纯的市场对等谈判产物，而是**行政指导（工信部）+ 国有运营商商业行为 + 跨境管制**三者叠加的产物。这套结构在视频流量主导时代已经显示出与海外不同的扭曲，AI Agent 流量结构会进一步把扭曲放大到新的方向。

## 4.1 三大运营商互联与"南北互联"问题

### 4.1.1 历史脉络

中国的骨干互联结构经过三次主要重组：

- **2000 年前**：邮电分营后形成中国电信、中国联通、中国网通三家全国骨干网，互联结算采用对等模式但实际严重失衡。
- **2002 年**：电信、网通南北分拆——中国电信主营 21 省（南方），中国网通主营 10 省（北方）。这是"南北互联问题"的起点：南北两网用户跨网访问需经骨干互联点中转，互联点拥塞与互访质量长期成为投诉焦点。
- **2008 年第二次重组**：联通与网通合并，电信整合 CDMA，移动整合铁通。形成沿用至今的"中国电信、中国联通、中国移动"三家全网格局。原"南北"问题转化为"三家之间互联"问题。

### 4.1.2 现状结算逻辑

三家运营商的互联结算**不是完全市场化**：

- 工信部历年下发的《电信网间互联管理规定》《电信网间互联结算办法》等文件，对结算单价与方向作出指导。
- 历史上长期由"主导运营商"（中国电信）向其他运营商支付互联费用，本质上是"内容多/出口多的一方付费"。
- 移动崛起、内容侧迁移到运营商各自体系外（BAT 自建 CDN）后，结算模型逐步调整。
- 公开监管文件参见 [工信部信息通信管理局](https://www.miit.gov.cn/jgsj/xgj/index.html) 历年发布。

### 4.1.3 与海外的根本差异

| 维度 | 海外（北美/欧洲） | 中国 |
|---|---|---|
| 主导力量 | Tier 1 ISP 之间的市场谈判 | 工信部行政指导 + 三大运营商商业 |
| 结算依据 | traffic ratio、peering ratio 阈值 | 监管文件 + 双边协议 + 历史定价 |
| IXP 角色 | DE-CIX、AMS-IX、LINX 等独立 IXP 主导 | 国家骨干直联点（CHN-IX、新设节点）+ 三大互联点 |
| 价格透明度 | TeleGeography 等公开 | 公开度低，多通过运营商集采公告与上市公司年报间接观察 |

## 4.2 国家骨干网体系

### 4.2.1 主要骨干网

| 骨干网 | 运营方 | 定位 | 跨境质量层级 |
|---|---|---|---|
| **ChinaNet（163）** | 中国电信 | 历史最久、覆盖最广的公网骨干 | 普通国际出口，质量一般 |
| **CN2 / CN2 GIA** | 中国电信 | 商用增值骨干，AS4809 | 跨境优质，溢价高 |
| **CN2 GT** | 中国电信 | CN2 经济版 | 跨境中等，介于 163 与 GIA 之间 |
| **CMNET** | 中国移动 | 移动公网骨干 | 海外节点逐步扩张 |
| **CUII / 169** | 中国联通 | 联通公网骨干 | 跨境质量稳定 |
| **CMI（中国移动国际）** | 中国移动 | 国际业务骨干 | 跨境优质 |

### 4.2.2 国家骨干直联点

工信部为缓解三大运营商互联拥塞，自 2013 年起陆续在多个城市设立**国家级互联网骨干直联点**。截至 2024 年公开报道，全国已设立 30 余个直联点（**Codex-A2 待补：具体清单需挂工信部历年新设公告 PDF，不能仅指向栏目首页**）。直联点提供：

- 三大运营商之间高速直连，绕开传统骨干互联点拥塞
- 部分允许 IDC、CDN、公有云接入

直联点制度的逻辑与海外 IXP（中立、多边对等）不同，**直联点本身的容量与互联规则由工信部审批**，公有云接入直联点需取得相应资质。

## 4.3 公有云与运营商的结算模式

### 4.3.1 多线 BGP 接入

公有云作为"内容侧"，必须解决"如何让三大运营商用户都能快速访问"这一问题。三种方案：

| 方案 | 实现 | 用户访问质量 | 公有云成本 |
|---|---|---|---|
| **单线** | 只接电信/联通/移动其一 | 跨网慢 | 最低 |
| **静态多线** | 接 2–3 家，IP 段静态分配 | 同线快、跨线绕骨干 | 中等 |
| **BGP 多线** | 申请独立 AS 号，BGP 同时宣告给三家 | 各运营商用户都直连 | 最高 |

公开 IDC 市场报价示意（一线城市机房，2024 年量级）：

- 单线 1 Gbps/月：¥8,000–15,000
- 静态多线 1 Gbps/月：¥20,000–35,000
- BGP 多线 1 Gbps/月：¥40,000–80,000

阿里云、腾讯云、华为云大型 region 节点几乎全部采用 BGP 多线，且各自持有自营 AS：

| 厂商 | AS 号 | RIR 注册名 | 上游/角色 |
|---|---|---|---|
| 阿里云 | [AS37963](https://bgp.tools/as/37963)、[HE](https://bgp.he.net/AS37963) | Hangzhou Alibaba Advertising Co.,Ltd.（前缀描述含 Aliyun Computing Co.LTD） | IPv4/IPv6 上游含中国电信、中国联通、中国移动 |
| 腾讯云 | [AS132203](https://bgp.tools/as/132203)、[HE](https://bgp.he.net/AS132203) | Tencent（注册于 2012-03-13，前缀描述含 Tencent cloud computing (Beijing) Co., Ltd.） | 中国大陆境内 |
| 华为云（国际） | [AS136907](https://bgp.tools/as/136907) | Huawei Cloud，APNIC 注册，Network type Content | 覆盖 HK / SG / JP / BR 等 POP |
| 华为云（大陆） | [AS55990](https://bgp.tools/as/55990) | Huawei Cloud Service data center（前缀描述 Huawei Public Cloud Service / Huawei Software Technologies Ltd.Co） | 中国大陆数据中心 |

各厂商在中国境内还有多个 AS，本研究只核到主要的一个（**Codex-A2 待补**：阿里云 AS45102 / 腾讯云 AS45090 等是否属于大陆自营口径需 APNIC/IRR 逐项核验）。这意味着公有云带宽采购成本中包含巨额三方运营商结算费用。

### 4.3.2 公有云出向带宽零售定价

国内三大公有云的出向带宽零售定价（按量+按峰值两种，2025 年量级）：

| 厂商 | 按量计费（¥/GB） | 按峰值带宽（¥/Mbps·月） | 计费方式 |
|---|---|---|---|
| 阿里云 | 0.8（中国大陆，多线 BGP） | 25（按固定带宽） | 多种计费模式 |
| 腾讯云 | 0.8（同上量级） | 25–30 | 按月、按 5 分钟峰值 |
| 华为云 | 0.8 量级 | 20–30 | 按需、包年包月 |

> 数据来源：各厂商官方价目页（[阿里云](https://www.aliyun.com/price/product#/ecs/detail)、[腾讯云](https://cloud.tencent.com/document/product/213/10578)、[华为云](https://www.huaweicloud.com/pricing.html#/ecs)）。具体数字会随促销、阶梯、地区变化，本表只取量级。

**关键观察**：国内云的入向带宽**同样免费**（与海外一致）。这意味着 AI Agent 客户在国内云上的入向激增同样不被计费——但云厂的采购成本（多线 BGP 带宽）是按总流量计的，本质上是被吞噬利润。

### 4.3.3 跨境出向带宽

涉及跨境时定价层级跃升。**口径说明**：以下三类价差不在同一计量单位上，比较时需注意。

- **按量价差**（¥/GB 口径）：国内云的**"国际加速"或"全球加速"产品**按量计费时，单价比国内出向高 5–10 倍（示意量级，需各厂商最新价目页核实）。
- **按峰值带宽价差**（¥/Mbps·月 口径）：大型企业申请**跨境专线（IPLC、MPLS-VPN）**，运营商单独审批；价格依带宽、目的地、合约期差异极大，渠道商报价中常见 1 Mbps/月 ¥1,000–3,000 量级，与国内 BGP 多线零售 ¥25–30/Mbps·月 量级相差**百倍以上**，但二者不是同一服务，比较仅供方向参考。
- **配额约束**：跨境带宽资源由国家级出口节点统一分配，受配额管制，是上述两类价差的根本来源。

**AI Agent 影响投射**：模型 API 几乎全部在境外，跨境推理调用直接撞到跨境带宽这堵墙。影响来自三类不同口径的成本结构叠加：**跨境按量服务高溢价（¥/GB 口径）+ 跨境专线高单价（¥/Mbps·月 口径）+ 国家级出口节点配额约束**——三者各自的"倍数"不能简单合并相加，但同向作用让跨境推理成本远高于国内调用。

## 4.4 ISP / IDC 牌照对结算路径的约束

中国互联网接入是牌照制：

- **基础电信业务（BSP）**：仅三大运营商持有
- **互联网接入服务（ISP）**：需工信部颁发增值电信业务许可证（A 类全国 / B 类省级）
- **IDC 业务**：同样需许可证
- **CDN 业务**：自 2017 年起单独纳入许可

牌照制带来的结算约束：

1. 公有云的 IDC 必须由持有 IDC 牌照的实体运营（自营或合作）
2. 流量必须经持牌运营商出口
3. 公有云与运营商之间的结算受牌照层级与监管要求约束

这与海外"任何 AS 都可以申请互联与对等"的开放模型完全不同。**对 AI Agent 流量的含义**：境内推理服务商如果想自建跨境骨干（类似 Google 的全球网络），面临的牌照门槛远高于海外同行。

## 4.6 与海外结算模式的根本差异

把前述结构对照海外，可以归纳为四点差异：

| 差异维度 | 海外模型 | 中国模型 | AI Agent 时代的影响 |
|---|---|---|---|
| 互联结算依据 | 流量对等、市场谈判 | 行政指导 + 监管文件 | 上下行反转触发的"重新议价"信号在中国传导慢 |
| 跨境带宽 | 多家海缆运营商竞争，价格透明 | 配额管制，国家级出口 | 模型 API 在境外 → 跨境带宽成为最强瓶颈 |
| 内容侧自建网络 | Google、Meta 自建全球骨干 | 受牌照限制，境内云只能采购运营商专线 | 境内推理服务商难以复制海外大厂的网络优化 |
| 利益分配 | 内容方-ISP 谈判 | 三家运营商 + 工信部 + 公有云的多方博弈 | "公平贡献费"如出现，制度路径与欧盟完全不同 |

**研究核心论断（**L4 推断**，待数据验证，留为开放假设）**：

> 中国语境下，AI Agent 流量对结算的冲击**更可能不以欧盟"公平贡献费"的形式出现**——更可能的路径是：(a) 工信部通过算力网络/东数西算工程，**鼓励并引导**推理算力境内部署；(b) 跨境带宽配额定向调整；(c) 三大运营商各自的"云+网"集成产品（移动云、天翼云、联通云）凭借自有网络优势在境内 AI Agent 服务上获得相对优势。
>
> 上述路径表述刻意从原稿"强制本地化"软化为"鼓励/引导本地化"，避免对监管意图作过强外推。

## 4.7 本部分小结

- 中国互联网结算是**行政+市场+管制**三层结构，与海外纯市场谈判不同
- 公有云通过 BGP 多线接入产生**巨额三方运营商结算成本**，但对客户仍保持入向免费
- 跨境带宽是 AI Agent 流量在中国的最强瓶颈，**境内推理算力本地化（鼓励/引导而非强制）**是政策最可能的回应路径
- 结算调整的政策信号需通过工信部文件、信通院白皮书、运营商年报三路追踪
