# AI Agent 流量经济学研究 — 目录草案 v0.4（结算视角 · 数据驱动）

研究焦点：**AI Agent 上行主导的流量结构，正在如何冲击国际 BGP 自治域结算、公有云带宽定价、中国公有云与 ISP 结算这三套既有商业模型？谁付费？谁受益？谁被错配？**

**叙事顺序调整**（采纳 Codex 建议）：先讲互联底座（BGP/容量批发），再讲云上零售（公有云定价），最后讲中国特殊结构。云定价是零售层，BGP/容量市场是成本底座，自下而上更清晰。

研究原则：
- 所有论断必须挂载可追溯的公开数据源；
- 行文中明示证据强度四级：**已观察事实 / 已发布数据 / 行业共识 / 本研究假设**；
- 凡缺乏公开数据支撑的论断（如"方向反转""入向免费不可持续""95th 失效"）一律降级为假设，留作"开放问题"，不冒充结论。
