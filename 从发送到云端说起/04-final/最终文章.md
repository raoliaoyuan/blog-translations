# 从「发送到云端」说起：AI 产业的四层棋局，与中美厂商的错综关系

## 引子：一个按钮

最近在用 Claude Code 时，我注意到一个不起眼的细节：一张「Suggested task」卡片上，除了「Start locally」「Fix in this session」，还多了一个选项——**Send to cloud**。

一个小按钮，却是这一年 AI 工具最重要转向的缩影：任务不再只在你眼皮底下的终端里跑，而是可以被「派」出去，在远端云环境里自主完成，再把结果交回来。

[Claude Code on the web](https://www.claude.com/blog/claude-code-on-the-web) 把这套体验搬进浏览器，每个云端会话在 Anthropic 托管的隔离环境里连接代码仓库、执行修改、跑测试，再交还给开发者 review。顺着这个按钮往下挖，它牵出的不是一个功能，而是整个 AI 产业正在发生的一次结构性重排。这篇文章把这条线索完整走一遍——并且把镜头同时对准中国和美国。

---

## 一、范式转变：从「身边的 copilot」到「可委派的同事」

云端执行最核心的价值，是把任务的生命周期和「人是否在场」解耦。

传统的本地 AI 编码是交互式的：你开着终端，实时盯着、纠偏。但 Agent 任务的特征恰恰是长、自主、可并行——一个重构加修测试的任务可能要跑几十分钟甚至几小时。让一个跑一小时的自主任务依赖你笔记本别合盖，本身就是错配。

云端执行解决的正是这个错配，它带来五个层面的变化：解绑在场（任务脱离设备独立运行）、从「盯一个」到「派一批」（开发者从驾驶单个 Agent 变成调度一支队列）、隔离带来更大胆的自主权、环境一致性（把 CI 思维延伸到 Agent 执行）、以及触发器解锁（定时、API、事件都能拉起任务）。

这不是某一家的动作。[OpenAI Codex](https://openai.com/index/introducing-codex/) 在 2025 年发布时就被定义为「可在云端并行处理软件工程任务的 agent」；[Google Jules](https://jules.google/) 是异步编码助手，在云端虚拟机里克隆仓库、改代码、提 PR；Claude Code 则从本地 CLI 扩展到浏览器和远程执行。更关键的是，云厂商没有止步于「卖模型 API」，而是把「Agent 运行时」做成新的基础设施品类——[AWS Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/) 把 Runtime、Memory、Gateway、Identity、Code Interpreter、Browser、Observability 拆成模块化服务；[Azure AI Foundry Agent Service](https://learn.microsoft.com/en-gb/azure/ai-services/agents/overview) 和 [Vertex AI Agent Builder](https://cloud.google.com/products/agent-builder) 走在同一方向。

以前，记忆、工具、权限、可观测性是开发者本地手工组装的概念框架；现在，云厂商正在把它们变成可计费的基础设施原语。一个小按钮的背后，是整条产业链的重新分工。

## 二、四层框架：芯片 → 云 → 大模型 → Agent 入口

要看清这盘棋，最有用的切法是把 AI 产业栈分成四层，自下而上：

1. **芯片层**：算力的物理底座（GPU、TPU、ASIC）。
2. **云计算层**：数据中心、供电、网络，以及把算力封装成服务的云平台与 Agent 托管运行时。
3. **大模型层（LLM）**：前沿模型的训练与提供。
4. **Agent 入口/运行时层**：离用户最近的产品与编排层，决定开发者在哪里创建任务、如何 review、怎样授权。

判断一个玩家的位置，关键不是它在某一层多强，而是**它同时覆盖了哪几层、每层用什么产品**。下面两张矩阵分别给出美国侧和中国侧的覆盖情况（单元格填具体产品，「—」表示未覆盖；术语：large language model 即大语言模型 LLM、application-specific integrated circuit 即专用集成电路 ASIC、Tensor Processing Unit 即张量处理单元 TPU）。

## 三、第一层 · 芯片：算力的物理底座

### 美国侧

**Nvidia** 仍是默认 GPU。其 [GB200 NVL72](https://www.nvidia.com/en-us/data-center/gb200-nvl72/) 把 36 个 Grace CPU 和 72 个 Blackwell GPU 组成机架级系统；[CoreWeave](https://www.coreweave.com/) 是其新一代 GPU 在云上商业化的重要渠道。但 Nvidia 真正的转变是从「卖 GPU」扩展成「GPU + 投资 + 运行时」：它通过 [NIM](https://www.nvidia.com/en-us/ai/)、[NeMo](https://www.nvidia.com/en-us/ai-data-science/products/nemo/)、[Nemotron](https://www.nvidia.com/en-us/ai-data-science/foundation-models/nemotron/) 向上渗透到模型工具链，同时大手笔投资下游客户（见第六节）。

**AMD** 以 [Instinct](https://www.amd.com/en/products/accelerators/instinct.html) 系列追赶。2025-10-06，OpenAI 与 AMD 宣布 [6GW GPU 多代部署协议](https://ir.amd.com/news-events/press-releases/detail/1260/amd-and-openai-announce-strategic-partnership-to-deploy-6-gigawatts-of-amd-gpus)，首批 1GW 基于 MI450、计划 2026 下半年部署；AMD 在 [8-K](https://ir.amd.com/financial-information/sec-filings/content/0001193125-25-230895/d28189d8k.htm) 中披露向 OpenAI 发行最多 1.6 亿股、每股 0.01 美元的认股权证——这是一种「以股权换采购」的绑定。

**三家云厂商的自研芯片**是这一层最重要的暗线：Google 的 [Cloud TPU](https://cloud.google.com/tpu)（支撑 Gemini，并向 Anthropic 大规模供货）、AWS 的 [Trainium/Inferentia](https://aws.amazon.com/ai/machine-learning/trainium/)、Microsoft 2026-01-26 发布的 [Maia 200](https://blogs.microsoft.com/blog/2026/01/26/maia-200-the-ai-accelerator-built-for-inference/) 推理加速器。它们的共同目的是降低对 Nvidia 的单一依赖。**Meta** 则与 Broadcom 合作开发自研 [MTIA](https://ai.meta.com/blog/meta-training-inference-accelerator-AI-MTIA/)。

**Broadcom 与 Marvell** 是藏在 hyperscaler 背后的「定制硅杠杆」。OpenAI 与 [Broadcom](https://openai.com/index/openai-and-broadcom-announce-strategic-collaboration/) 在 2025-10 宣布共同部署 10GW OpenAI 自研加速器；Anthropic 在 2026-04 宣布与 [Google、Broadcom](https://www.anthropic.com/news/google-broadcom-partnership-compute) 签下数 GW 级下一代 TPU 容量，自 2027 年起上线。Marvell 则在 2026-03-31 获得 Nvidia [20 亿美元战略投资并加入 NVLink Fusion 生态](https://investor.marvell.com/news-events/press-releases/detail/1019/nvidia-ai-ecosystem-expands-as-marvell-joins-forces-through-nvlink-fusion)——Nvidia 投资一个为客户做「Nvidia 替代品」的 ASIC 设计方，本身就是把潜在替代者纳入自己互连标准的防御动作。

这一层无法绕开**出口管制**：美国商务部工业与安全局（BIS）在 [2023-10-17](https://www.bis.gov/press-release/commerce-strengthens-restrictions-advanced-computing-semiconductors-semiconductor-manufacturing-equipment) 收紧先进计算芯片对华出口，又在 [2025-05-13](https://www.bis.gov/press-release/department-commerce-announces-rescission-biden-era-artificial-intelligence-diffusion-rule-strengthens) 撤销「AI Diffusion」规则。管制的另一面，正是中国国产替代的加速。

### 中国侧

中国芯片层的主线是**国产替代与软硬一体**。**华为昇腾（Huawei Ascend）** 是国产第一梯队的核心，其价值不在单一型号，而在 [昇腾](https://www.hiascend.com/) + CANN 软件栈 + [ModelArts](https://www.huaweicloud.com/intl/zh-cn/product/modelarts) + [盘古](https://www.huaweicloud.com/product/pangu) 行业模型的整套闭环，尤其在政企、能源等场景。**百度昆仑芯**（[Kunlunxin](http://www.kunlunxin.com/)）、**阿里平头哥含光 800**（[T-Head](https://www.t-head.cn/product/npu)，官方定义为数据中心推理芯片）、**腾讯紫霄**（在 [2021 可持续社会价值报告](https://static.www.tencent.com/attachments/ssv/2021/TencentSSVReport2021.pdf) 中披露的自研推理芯片）则更多是各自集团内部基础设施的一部分，对外产品叙事弱于昇腾。

**寒武纪（Cambricon）** 是这层里少有的纯芯片上市公司（上交所科创板 688256，[官网](https://www.cambricon.com/) / [上交所披露](https://static.sse.com.cn/stock/disclosure/announcement/c/202506/688256_20250604_5OJ3.pdf)），其思元系列在国产 AI 加速卡和智算集群上与昇腾、昆仑芯正面竞争。

> 需要诚实标注的是：关于「字节跳动自研推理芯片已流片」「壁仞/昆仑芯 IPO 时间表」「昇腾年产能突破百万片」等 2026 年具体说法，本文核查时未找到公司官方一手页面支持，故不作为事实写入（结构性推断：以上各家都有强烈的算力自给动机，但动机不等于已落地的官方产品）。

## 四、第二层 · 云计算

### 美国侧

美国云层是「三巨头 + 中立产能」的格局。

**AWS** 同时提供通用云、自研芯片、[Bedrock](https://aws.amazon.com/bedrock/agentcore/) 模型平台与 AgentCore 运行时，是「基础设施默认选项」。它一边深度绑定 Anthropic（主要云与训练伙伴），一边在 2026-02-27 拿下 [OpenAI 的合作](https://openai.com/index/amazon-partnership/)，成为 OpenAI Frontier 的独家第三方云分发方。**Microsoft Azure** 长期是 OpenAI 的主要云与商业通道；2026-04-27 双方 [修订协议](https://openai.com/index/next-phase-of-microsoft-partnership/) 后，Microsoft 仍是主要云伙伴，但 OpenAI 可跨任意云服务客户。**Google Cloud** 的差异化在 [TPU](https://cloud.google.com/tpu) 与 Vertex AI——Claude 同时可通过 AWS Bedrock、[Google Cloud Vertex AI](https://www.anthropic.com/news/google-broadcom-partnership-compute) 和 Microsoft Foundry 三云获取。

**Oracle** 通过 [OCI](https://www.oracle.com/cloud/) 和 Stargate 项目切入：2025-01-21 OpenAI 公布 [Stargate Project](https://openai.com/index/announcing-the-stargate-project/)，计划四年投资 5000 亿美元、立即部署 1000 亿美元，初始股权出资方为 SoftBank、OpenAI、Oracle、MGX，初始技术伙伴含 Arm、Microsoft、Nvidia、Oracle。**CoreWeave** 则是以 Nvidia GPU 为核心的专业 AI 云，本质是一个高度依赖 Nvidia 供应的「中立产能」渠道。

### 中国侧

中国云厂商已从「算力租赁商」进化为「模型调度员」，竞争焦点是 **MaaS（Model as a Service，模型即服务）平台**。**阿里云**以 [百炼 Model Studio](https://help.aliyun.com/zh/model-studio/what-is-model-studio) 为一站式大模型开发平台，集成千问及第三方模型、提供兼容 OpenAI 的 API；**华为云**靠 [盘古 + ModelArts Studio](https://support.huaweicloud.com/productdesc-pangulm/pangulm_01_0001.html) 的软硬一体在政企市场见长；**百度智能云**以 [千帆 AppBuilder](https://cloud.baidu.com/doc/AppBuilder/s/build-rag-workflow-app) 提供 RAG、Agent、工作流工具链；**腾讯云**的差异化在微信/企业微信/腾讯会议等入口与 [混元](https://cloud.tencent.com/product/tclm)、[ADP](https://adp.cloud.tencent.com/) 的结合；**火山引擎**靠字节内部高并发推荐/广告经验，以 [火山方舟](https://www.volcengine.com/product/ark) 在低延迟推理和多模态生成上竞争。

## 五、第三层 · 大模型（LLM）

### 美国侧

**OpenAI** 与 **Anthropic** 是最强的两家独立模型公司，也是被资本和算力争夺得最厉害的两家。OpenAI 的 [GPT 系列](https://platform.openai.com/docs/models) 同时接受 Microsoft、Amazon、Nvidia、AMD 的资金与渠道；Anthropic 的 [Claude](https://www.anthropic.com/claude) 则把模型同时跑在 AWS Trainium、Google TPU 和 Nvidia GPU 上，并通过三大云分发。

**Google DeepMind** 的 [Gemini](https://deepmind.google/models/gemini/) 与 TPU、Vertex AI、AI Studio 形成内生闭环，是少数四层全栈玩家的模型层。**Meta** 走开放权重路线，用 [Llama](https://www.llama.com/) 和自有社交分发压低别人的定价空间。**xAI** 则更像垂直玩家：用 Nvidia GPU 自建 [Colossus 超算](https://investor.nvidia.com/news/press-release-details/2024/NVIDIA-Ethernet-Networking-Accelerates-Worlds-Largest-AI-Supercomputer-Built-by-xAI/)（10 万颗 Hopper GPU + Spectrum-X 网络），[Grok](https://x.ai/grok) 既是模型又是入口；2024 年它先后完成两轮各 60 亿美元的 [Series B](https://x.ai/news/series-b) 和 [Series C](https://x.ai/news/series-c)。

### 中国侧

中国大模型层呈现「大厂自研 + AI 创业公司」并存的格局。大厂自研：阿里 [通义千问 Qwen](https://github.com/QwenLM/Qwen3)（开源权重 + 百炼商业化）、百度 [文心 ERNIE](https://ernie.baidu.com/blog/zh/posts/ernie4.5/)、腾讯 [混元](https://cloud.tencent.com/product/tclm)、字节 [豆包](https://www.volcengine.com/product/ark)、华为 [盘古](https://www.huaweicloud.com/product/pangu)。创业公司：[DeepSeek](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)（以高性价比 API 和推理模型形象著称，直接推动国内 Token 价格下行）、[智谱/Z.ai](https://docs.bigmodel.cn/cn/guide/start/introduction)、[月之暗面 Kimi](https://www.moonshot.cn/)、[MiniMax](https://ir.minimax.io/zh-HK)。

这一层的中国特色是**大厂资本与模型创业公司的交织**（以下持股为招股书/报道口径）：MiniMax 上市后，阿里巴巴持股约 [12.52%](https://www.recodechinaai.com/p/zhipu-ai-and-minimax-just-went-public)、腾讯约 2.37%；智谱获阿里、腾讯、小米、美团及国资基金支持；月之暗面由阿里、腾讯等支持。换言之，几家大厂既自研模型、又投资创业模型公司、又用云平台分发它们——这正是下一节要讲的「三重身份」。

## 六、第四层 · Agent 入口/运行时

这是离用户最近、粘性最高的一层，也是 2026 年最激烈的战场。

### 美国侧

开发者入口侧，[Claude Code](https://www.anthropic.com/product/claude-code)、[OpenAI Codex](https://openai.com/index/introducing-codex/)、[Google Jules](https://jules.google/)、[Cursor](https://cursor.com/)、[GitHub Copilot](https://github.com/features/copilot) 正面厮杀。其中 Cursor 是典型的「模型路由 + 编辑器入口」，[同时路由 OpenAI、Anthropic、Google、xAI 等竞争模型](https://docs.cursor.com/models/)，被夹在模型供应商和代码托管平台之间。

企业运行时侧，[Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/)、[Azure AI Foundry Agent Service](https://learn.microsoft.com/en-gb/azure/ai-services/agents/overview)、[Vertex AI Agent Builder](https://cloud.google.com/products/agent-builder) 三家云在竞争。它们的共同逻辑，是让云厂商在不完全自研 frontier 模型的情况下，通过控制身份、审计、工具调用、账单和算力承诺来「圈住」客户——把外部 LLM 重新「云化」成自家原生运行时。

### 中国侧

中国 Agent 层同样是「大厂矩阵 + 编码工具」：阿里 [百炼智能体](https://help.aliyun.com/zh/model-studio/single-agent-application) + [通义灵码 Lingma](https://help.aliyun.com/zh/lingma/)、百度 [千帆 AppBuilder](https://cloud.baidu.com/doc/AppBuilder/s/build-rag-workflow-app) + [Comate](https://comate.baidu.com/)、腾讯 [ADP](https://adp.cloud.tencent.com/) + [CodeBuddy](https://cloud.tencent.com/product/acc)、字节 [Trae](https://www.trae.cn/) + [火山方舟](https://www.volcengine.com/product/ark)。它们的潜在壁垒各不相同：腾讯靠微信/企业微信/腾讯文档生态，字节靠豆包流量与端侧体验，阿里靠 Qwen 开源生态 + 云 API，百度靠搜索与知识库。

## 七、错综关系网：供货 × 持股 × 竞争

把上面四层的事实摊开，会浮现出这一波 AI 产业最微妙的结构：**同一家公司，常常同时是你的算力供应商、你的投资人、和你的产品竞争对手。**

### 美国侧：两端争夺，谁也不想被夹在中间

围绕 **OpenAI** 的资本-供货网，是「三重身份」最极端的样本：

- Microsoft：主要股东 + 主要云（Azure）+ 模型集成（Copilot/GitHub Copilot）+ 入口竞争者。2026-04-27 修约后，IP 许可延续到 2032 年但改为非独家，收入分成持续到 2030 年（[OpenAI](https://openai.com/index/next-phase-of-microsoft-partnership/)）。
- Amazon：2026-02-27 宣布投资 [500 亿美元](https://openai.com/index/amazon-partnership/)（150 亿先投、350 亿后续），并成为 OpenAI Frontier 独家第三方云分发方、OpenAI 将消耗约 2GW Trainium（[aboutamazon](https://www.aboutamazon.com/news/aws/amazon-open-ai-strategic-partnership-investment)）。
- Nvidia：2025-09 原定 [10GW、最高 1000 亿美元](https://openai.com/index/openai-nvidia-systems-partnership/) 的部署式投资意向；据 2026 年 2–3 月公开报道，该安排已重组为约 300 亿美元的直接股权，计入 OpenAI 1100 亿美元新一轮、于 3 月底以约 8520 亿美元估值收尾（[CNBC](https://www.cnbc.com/2026/02/27/open-ai-funding-round-amazon.html)）。
- AMD：6GW 采购 + 1.6 亿股认股权证（[AMD 8-K](https://ir.amd.com/financial-information/sec-filings/content/0001193125-25-230895/d28189d8k.htm)）。
- Broadcom：10GW 自研加速器共同开发（[OpenAI/Broadcom](https://openai.com/index/openai-and-broadcom-announce-strategic-collaboration/)）。

围绕 **Anthropic** 是另一张几乎对称的网：Amazon 此前已投 80 亿美元，2026-04-20 再投 [50 亿美元、未来最高 200 亿美元](https://www.anthropic.com/news/anthropic-amazon-compute)，Anthropic 承诺十年内向 AWS 投入超 1000 亿美元、部署最高 5GW Trainium，估值约 3800 亿美元；2025-11-18，[Microsoft、Nvidia 分别承诺最高 50 亿、100 亿美元投资](https://blogs.microsoft.com/blog/2025/11/18/microsoft-nvidia-and-anthropic-announce-strategic-partnerships/)，Anthropic 承诺购买 300 亿美元 Azure 算力；Google 早期以约 3 亿美元换取约 10% 股权、并承诺投资 20 亿美元（[CNBC 2023](https://www.cnbc.com/2023/10/27/google-commits-to-invest-2-billion-in-openai-competitor-anthropic.html)），又向其供给最高 100 万颗 [TPU](https://www.anthropic.com/news/expanding-our-use-of-google-cloud-tpus-and-services)。

把这些放在一起，美国侧的最优策略是一个**杠铃**：顶端攥住产品/入口、底端控住芯片/产能，中间的「具体跑在哪家云」反而要多云分散、避免被单一绑定。真正危险的位置，是「上不沾入口、下不控产能」的中间夹层。Google、Amazon、Microsoft 三家四层全栈，最不容易被夹；OpenAI、Anthropic 顶端最强但底端依赖外部，所以要用股权和长约把多家算力供应商都绑上。

### 中国侧：全栈大厂的「三重身份」

中国侧的「三重身份」集中体现在云厂商身上：阿里云、华为云、百度智能云、腾讯云同时是**投资者**（投资模型创业公司）、**开发者**（自研 Qwen/盘古/文心/混元）、**平台方**（MaaS 平台上既卖自研模型也卖被投公司模型）。阿里既投 MiniMax、月之暗面、智谱，又自研 Qwen，又用百炼分发——和被投公司形成「赛马」。

不过有一点必须诚实：**中国侧的具体持股比例，官方一手披露远比美国稀缺**。除 MiniMax、智谱等已 IPO 公司可从招股书读到部分数据外，大量「某大厂持某模型公司 X%」的说法只有媒体口径、缺乏公司公告支撑。本文的稳妥写法是：大厂的资本、云资源和模型平台，共同影响创业模型公司的算力获取、API 分发和商业化路径——而不把未经官方披露的百分比当成事实。

### 跨国交织

两张网并非隔绝。出口管制是最强的耦合点：BIS 的 [先进计算管制](https://www.bis.gov/press-release/commerce-strengthens-restrictions-advanced-computing-semiconductors-semiconductor-manufacturing-equipment) 一边限制 Nvidia 高端 GPU 对华出口，一边反向催熟了昇腾、昆仑芯、寒武纪的国产替代;而中美两侧不约而同地走向「自研芯片对冲通用 GPU」——美国是 TPU/Trainium/Maia/MTIA，中国是昇腾/昆仑芯/含光，逻辑同源。

## 八、结语：一个小按钮，一张大棋盘

回到那个「Send to cloud」按钮。它表面上只是让一个任务跑去云端，但顺着它，我们看到的是：

- **一个工具范式的转变**：从 copilot 到可委派的同事；
- **一个全行业的方向**：Agent 集体云化，云成为 Agent 托管平台；
- **一场产业的重排**：芯片、云、模型、入口四层交织，资本、供货、竞争三股力量缠绕；顶端争入口，底端争产能，中间求韧性。

中美两盘棋的形状不同：美国是「三家全栈巨头 + 两家顶端模型公司 + 一批中立产能」，靠股权和长约把算力锁死；中国是「四家全栈大厂 + 一批纯模型/纯芯片玩家」，在出口管制下被迫把芯片自给提到战略高度。但底层逻辑相通——**谁能同时够到顶部入口和底部算力，谁就不容易被夹在中间。**

如果想继续追踪这盘棋往哪走，我会盯三个一手信号：

1. **自研芯片的自有部署占比**：TPU/Trainium/Maia/MTIA 与昇腾/昆仑芯，谁在真正降低对 Nvidia 的依赖。
2. **模型厂商 Agent 运行时 vs 云厂商 Agent 平台的功能重叠度**：AgentCore/Foundry/Vertex 与 Claude Code/Codex/Jules 的边界之争会不会白热化。
3. **模型层的可替代性**：多模型路由（如 Cursor、百炼、火山方舟）能走多远，决定「持股 + 供货」的巨头还能不能拿捏模型厂商。
